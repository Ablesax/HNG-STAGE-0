# HNG-STAGE-0
This is the codebase for my HNG stage 0 project where i had to build a small accessible responsive profile card component page using html and mordern front end patterns 

To run this project locally , all you need to do is either you clone the repository to you directory on you personal system or you download the folder of this project 
After getting the project folder,open a IDE(Integrated Development Environment) e.g vscode and open the folder through the IDE and run the index.html file .
The result shows on a browser which is usually internet explorer or chrome by default.
You can tweak the syling on the index.css page and the interactivity and functionality from the index.js file while all text and pictures rendereded can be changed from the index.html file.
